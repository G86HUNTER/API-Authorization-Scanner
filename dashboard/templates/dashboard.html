About This Framework

This tool helps authorized penetration testers and developers identify potential authorization weaknesses in REST APIs:

  • BOLA — Broken Object Level Authorization: can a user access resources owned by another user?
  • BFLA — Broken Function Level Authorization: can a lower-privileged user invoke admin functions?

Results are preliminary estimates. Manual validation by a qualified security professional is required before treating any finding as a confirmed production vulnerability.
